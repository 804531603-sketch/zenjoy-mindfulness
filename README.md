# 禅悦 · 正念打卡小程序（开源版）

一个极简、干净、可以直接编译运行的微信小程序：
**每日正念打卡 + 疗愈频率音 + 呼吸引导 + 里程碑徽章 + 打卡海报。**

没有花哨的依赖，没有后端强制要求 —— 不开通云开发也能完整跑起来（自动降级为纯本地存储）。

> 这是「禅悦正念」小程序的代码部分。**内容资产（冥想引导逐字稿、禅语库、公众号二维码）不在本仓库内**，
> 详见下方「许可」一节。

---

## 功能一览

| 模块 | 内容 |
|---|---|
| 首页 | 今日日期、连续打卡天数、累计分钟、本月日历格点亮、开始冥想、打卡弹窗（时长 + 心情 + 随笔） |
| 冥想页 | 全屏深色星空、每日禅语、4-4-4 呼吸圆环、已静坐计时、音轨切换、定时停止 |
| 后台播放 | `BackgroundAudioManager` 单例 + `requiredBackgroundModes: ["audio"]`，切后台/锁屏续播 |
| 定时停止 | 目标时间点 `stopAt` + `onTimeUpdate` 双重校验，后台不失效 |
| 徽章 | 3 / 7 / 21 / 50 / 100 天五档里程碑墙，达标自动解锁 |
| 打卡海报 | 生成唯美星空海报（天数 + 今日禅语 + 日期），保存相册发朋友圈 |
| 云同步 | 可选。填云开发环境 ID 即启用；不填则纯本地，换机不同步 |
| 打卡提醒 | 可选。云函数 + 订阅消息，每晚定时提醒当天没打卡的用户 |

---

## 技术栈

- 微信小程序原生（无框架、无 npm 依赖）
- 微信云开发（可选：云数据库 / 云函数 / 云存储）
- 音频：`BackgroundAudioManager`（音乐）+ `InnerAudioContext`（人声引导）

包体约 **1MB 出头**，无分包，无需域名备案即可提审（音频走 https 直链或云存储 `cloud://`）。

---

## 快速开始

1. **导入**：微信开发者工具 → 导入项目 → 选择本目录
2. **换 AppID**：在 `project.config.json` 里把 `appid` 换成你自己的（[申请入口](https://mp.weixin.qq.com/)）
3. **编译**：直接可看首页 → 点「开始冥想」进入冥想页
4. **接音频**：把你的 mp3 放到自己的存储或云存储，改 `config/host.js` 里的 `HOST`（或改用 `cloud://` fileID）
5. **（可选）开云同步**：开发者工具点「云开发」→ 开通 → 把环境 ID 填进 `utils/cloud.js` 的 `ENV_ID`

> 第 4 步没做时，界面照常运行，只是没有声音。开发阶段可在「详情 → 本地设置」勾选
> 「不校验合法域名」用外链测试，但**正式提审前必须换成自有存储**。

## 使用前需要注意

- **音频素材请自备，并确认可商用**。仓库不含任何音频文件，`tracks.js` 里是占位地址。
- **云函数里的敏感常量必须自己填**：`dailyRemind` 的订阅消息模板 ID、`zenjoyAdmin` 的后台密码。
  后台密码请务必改成强密码 —— 那个页面能看到访客记录和留资联系方式。
- **访客记录合规**：本项目示范的采集仅使用微信自动下发的 `openid`（无法反查真人身份），
  联系方式必须由用户手填自愿提交。使用者需自行遵守《个人信息保护法》与微信小程序隐私规范。
